# Netflix Content Analysis Dashboard | Power BI

## 📊 Project Overview

An interactive Netflix Content Analysis Dashboard developed using Microsoft Power BI to analyze content distribution, release trends, content types, categories, age groups, directors, and locations.

## 🎯 Business Objective

The objective of this project is to transform Netflix content data into meaningful visual insights and support data-driven understanding of the Netflix content library.

The dashboard answers questions such as:

- What is the total number of Netflix titles analyzed?
- How is content distributed between Movies and TV Shows?
- Which age categories contain the most content?
- Which categories have the highest content representation?
- How does content vary across release years?
- How does content distribution vary by location?

## 💡 Key Insights

- Movies represent a larger share of the analyzed Netflix content.
- The dashboard highlights content distribution across different age categories.
- Category-level analysis helps identify areas with stronger content representation.
- Release-year analysis provides an overview of content trends over time.
- Location filtering enables comparison of Netflix content across different regions.
